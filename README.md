# Dynamo Kyjev — klubový web

Responzívny univerzitný projekt o futbalovom klube Dynamo Kyjev. Rozhranie a ukážkový obsah sú v slovenčine. Web používa React, TypeScript, Vite a React Router.

## Spustenie lokálne

1. Nainštalujte Node.js 20 alebo novší.
2. V koreňovom priečinku projektu nainštalujte závislosti:

	```bash
	npm install
	```

3. Spustite vývojový server:

	```bash
	npm run dev
	```

4. Otvorte adresu zobrazenú v termináli, predvolene `http://localhost:5173`.

## Dostupné príkazy

- `npm run dev` — vývojový server s automatickým obnovením.
- `npm run build` — kontrola TypeScriptu a produkčná zostava.
- `npm run preview` — lokálne zobrazenie produkčnej zostavy.

## Obsah a údaje

Stránky, profily, zápasové termíny, výsledky, zostavy a štatistiky sú demonštračné; nepredstavujú aktuálne oficiálne informácie klubu. Historické míľniky sú stručným prehľadom verejne známych udalostí.
